# v1.1.0 验证记录

环境：Windows x64、官方 DeepSeek Harness 0.2.1-rc.5、Node.js 24、Python 3.12 / PySide6，Windows 程序使用 PyInstaller 构建。

## 自动检查

- 12 项 Node 测试通过：真实事件格式、多会话独立完成、等待回应、取消与错误、余额字段过滤、入口认证、下载校验、失败回退、安装与个人数据保留。
- 126 项 Python 测试通过：动画绑定、播放规则、音频和字幕、语音触发频率、窗口与设置、余额刷新、锁定穿透、图标、启动联动、更新与配置迁移。
- 构建后的 EXE 使用系统 PATH 运行 `--verify-package`，不依赖开发机的 Python。字体、83 个 GIF、音频解码与输出、完整设置、额度反馈、透明度、更新来源等检查通过。
- 对实际绘制图像检查透明度：锁定悬停时角色和余额框一起淡化，移出恢复；余额框刷新、调整大小和小锁仍可操作。

## 官方 Harness 实际联调

在独立验证 profile 中运行完整版插件，使用合成测试文件完成：读取 → 写摘要 → 重新读取 → 提问等待 → 完成。状态桥接捕获思考、查阅、编写、等待和完成；桌宠捕获对应动画与完成提醒。

一个会话等待回应时，另一个会话完成，仍生成独立完成事件。随后结束第一个会话，也有完成动画并回到待机。账户余额经官方账户服务读取，桌宠报告实时连接与余额可用；没有将金额、账号或聊天记录放入仓库。

完整设置窗口、GIF 素材库、逐条语音字幕与保存迁移页已实际打开；语音预览可以播放。发布用 TGZ 经 Harness CLI 安装后，检查其代码与固定下载摘要和源码一致；从插件入口启动的程序版本为 1.1.0，并能读取实时余额。

## 升级与迁移

- 从原独立版导出配置素材包，导入新版后再导出完整便携包。
- 在包含中文与空格的新目录解压后，再运行 EXE 检查，全部通过。
- 核验所有导出文件 SHA-256：83 个 GIF、40 个音频、54 组语音字幕配对、两款字体及个人设置保留。
- 修改后的音量、文本、绑定和透明度可保存、导出、导入；连接路径在便携包中重置。
- 卸载、重新安装插件后，插件目录之外的个人配置和素材保留；更新程序时保留上一份程序目录。
- 本版不包含创建桌面快捷方式按钮或脚本，不携带账户凭据和会话内容。

## 发布后检查

- 官方 Harness CLI 从固定 Git 提交安装成功，安装后的代码与发布源码一致。
- 从 GitHub Release 实际下载完整程序，大小、SHA-256、解压安装与版本标记检查通过。
- 公开附件的大小与 SHA-256 均与本地验证包一致。

## 范围

验证的是 Windows 本机 Harness；未验证 macOS、Linux、远程服务器或其他 Harness 版本。社区收录由市场维护者审核，这份记录不代表已经获准上架。
