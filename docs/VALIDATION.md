# v1.1.1 验证记录

环境：Windows x64、官方 Harness CLI 0.2.1-rc.5、Node.js 24、Python 3.12.14 / PySide6 6.11.2 / PyInstaller 6.22.3。完整程序从干净源码提交 `6a451c2ad93bfcd70f986031ab807af3a1368061` 构建；包内 `BUILD_INFO.json` 记录具体依赖。

## 本次修复与自动检查

- 131 项 Python 测试通过。新增回归覆盖 JSON 界面导入、旧 ZIP 导入、本机路径保存、异常 appearance 类型及两种 ZIP 导出：导入/迁移清空外来 DeepSeek 路径，正常启动仍保留本机数据目录；语音字幕、动画、字体、尺寸及其他设置保留。
- 12 项 Node 测试通过：真实事件格式回放、多会话完成、等待/取消/错误、余额字段过滤、入口认证、固定下载校验、失败回退与个人数据保留。
- 删除无入口的客户端启动函数、连接安装函数及不存在的安装脚本引用；移除无实际用途的客户端可执行路径设置。旧配置中的该字段在加载时丢弃。
- 构建出的 EXE 在系统 PATH 下通过 `--verify-package`：设置面板、字幕配对、语音策略、字体、音频解码与输出、缩放、静音、悬停锁、点击穿透、角色和余额共同淡化、额度点击反馈、更新来源、图标与启动联动。
- 包内测试还实际应用了含外来路径的配置，确认路径已清理且不存在可执行路径控件。

## 托管启动与状态

通过实际 `DesktopManager` 启动新版 EXE，并使用隔离数据目录发送合成 Harness 事件与余额。观察到思考 `p1-12`、查阅 `p2-07`、编辑 `p2-06`、完成 `p1-20`，余额读取可用，隐藏与正常关闭有效。

这是实际 EXE 与连接入口的联调，事件与余额为模拟数据。本轮没有重新登录真实账户或发起真实计费任务；之前的真实账户/任务验证见 [v1.1.0 记录](https://github.com/Doya16/dsh-shorekeeper/blob/v1.1.0/docs/VALIDATION.md)。
