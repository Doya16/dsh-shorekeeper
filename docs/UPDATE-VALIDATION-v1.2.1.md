# v1.2.1 签名更新验证

本版修复：一键更新此前只依赖发布元数据里的哈希。当这些元数据、清单和程序包都经第三方镜像传输时，镜像可以同时伪造。现在清单必须带发布者离线密钥的 Ed25519 签名，公钥内置在程序中；程序包和每个程序文件的哈希都来自已签名清单。
实机测试还发现并修复了一处问题：更新状态文件被其他进程短暂占用时，Windows 拒绝替换，会造成不必要的回滚。现在会在 10 秒内重试。

## 验证环境

Windows 11 x64，Python 3.12.14 / PySide6 6.11.2 / PyInstaller 6.22.3。158 项 Python 测试在无窗口模式下通过，其中包含 RFC 8032 测试向量和伪造镜像回归测试；300 组随机签名与独立的 cryptography 库交叉验证一致。

下列场景运行从干净提交构建的打包 EXE：未加测试入口，点击为真实鼠标事件。GitHub 和镜像由本机代理模拟（真实 TLS，测试 CA 仅对测试进程生效）。测试目录隔离，每个升级场景校验 254 个素材哈希和个人设置。
