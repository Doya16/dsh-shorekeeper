# 数据与运行说明

本版为 Windows 本机桌宠，不适用于让远程服务器代为运行桌面程序。

- Harness 插件读取会话生命周期、工具名称和结束原因；只向本机桌宠写入状态、匿名会话编号、时间、余额。不会把提示词、命令参数、工具输出、文件内容或推理文本写入状态文件。
- 余额通过 Harness 的 `deepseekAccount.getBalance` 服务读取，不直接读取密码、API Key 或登录凭据。余额仍会经官方 Harness 账户服务正常请求。
- 插件无 npm postinstall、混淆代码或修改 Harness 程序文件的操作。完整桌宠是 Python/PySide6 编译出的 Windows 程序，源码随仓库公开。
- 首次点击安装时，从本仓库固定 Release 下载 Windows 完整包，或经用户选择的 GH-Proxy 下载同一公开文件。SHA-256、大小和版本固定在 `runtime-manifest.json`。镜像只能替换下载路线，不能绕过校验。
- 解压使用仓库内的 PowerShell/.NET 脚本，不要求管理员权限。解压前检查路径、重复条目、符号链接和解压大小。
- 点击启动、打开设置，或用户勾选随 Harness 启动后，插件运行固定路径的桌宠 EXE。没有任意 shell 命令或自选可执行路径接口。
- 控制入口使用 Harness 身份校验，以及同源随机令牌。安装、启动、隐藏、关闭和设置使用固定操作名单。
- 完整程序的更新检查访问本项目公开 GitHub Release 或选定镜像。仅检查不会下载安装；用户点击“一键更新”后，下载并校验程序包，由独立助手执行安装与重启。用户操作“打开素材目录”等按钮时会使用 Windows 文件选择器或资源管理器。
- 数据位于 `$DSH_HOME/shorekeeper-market`（默认用户目录 `.dsh` 下）。`app` 存储设置和素材；状态与刷新请求放在外层。卸载插件保留用户数据。
- JSON/ZIP 导入及两种 ZIP 导出会重置本机连接路径、固定会话和屏幕位置。已移除旧的自选客户端可执行路径、启动客户端函数及失效连接安装脚本入口；正常启动仍保留用户在本机选择的数据目录。
- Windows 完整包内的 `BUILD_INFO.json` 记录源码提交与构建依赖；构建步骤见 [BUILD.md](BUILD.md)。该记录不是独立构建证明，文件摘要也不等于源码与二进制一致性的证明。
- 插件关闭时默认关闭其管理的桌宠；取消“随 DeepSeek 完全退出而关闭”可保留桌宠。关闭窗口但客户端仍在托盘运行不会卸载插件。
- 创建快捷方式功能已移除。市场托管启动时不写 Windows 启动注册表。手动运行导出的独立便携程序并选择启动联动时，保留独立程序原有的当前用户启动联动功能。

以上是本版行为和检查范围，不代表经过独立安全审计。

## 一键程序更新与中断恢复

- 已安装用户下载固定项目的程序包，不重新下载个人素材。npm 清单固定程序 ZIP 及逐文件大小、SHA-256；桌宠自行更新时，清单必须带有发布者离线密钥的 Ed25519 签名，公钥内置在程序中；再按已签名的清单校验 ZIP 和每个程序文件。第三方镜像只负责传输，无法伪造可安装的更新，但可能延迟、不可用，或显示实际无法安装的版本提醒。镜像来源不显示更新说明。
- 包含标准库构建的启动器与更新助手，不包含额外的远程脚本入口。程序文件路径有白名单，配置、GIF、音频、字体和默认素材禁止被程序包覆盖。ZIP 路径、重复项、符号链接、大小均受检查。
- 版本目录完整写好后才切换指针。更新前备份即将覆盖的程序文件与配置；收到匹配版本、PID 和随机更新标识的持续健康状态后才提交。失败或下次启动发现未提交事务时恢复备份。清理仅处理安装目录内带有本次标识、且所属进程已退出的下载缓存。
- 自动检查默认每 6 小时一次，可关。常驻提醒无声音，可当天免提醒；下载和安装仍需要用户点击。没有新增管理员权限、账户权限或 npm 安装钩子。
