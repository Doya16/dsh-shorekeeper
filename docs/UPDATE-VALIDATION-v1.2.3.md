# v1.2.3 升级入口验证

本版只改插件，完整程序仍是 v1.2.2，程序下载地址、大小和 SHA-256 不变，因此没有新的程序 Release。

## 问题

更新或重装插件不会改动 `~/.dsh/shorekeeper-market/app`。从 1.1.x 升级插件后，桌宠程序仍是旧版，而部署入口在首次安装后已自动隐藏，更新按钮只留在 Harness 设置页。1.1.x 程序本身没有一键更新，它的更新窗口只能下载文件，所以用户容易一直停留在旧程序。

## 改动

- 程序版本低于插件固定的版本时，部署入口重新出现并展开“更新并重启守岸人”。下载仍需用户点击。
- 面板可以收起；更新完成后恢复用户原来的入口显示设置。
- 面板提示忽略旧版桌宠弹出的更新窗口。

## 验证

- 35 项 Node 测试通过，新增 5 项运行真实入口组件的测试。Python 代码未改动，未重新运行。
- 真实 DeepSeek Harness 0.2.1-rc.5（隔离 profile），安装 1.2.3 候选包，并使用一份真实的 v1.1.1 程序和设置副本，入口设置为已隐藏，随 Harness 自动启动：
  - 右侧面板自动展开，显示“已安装 v1.1.1 · 运行中”和更新按钮。
  - 点击后经真实 GitHub 下载并校验程序包，关闭运行中的旧版桌宠，升级到 v1.2.2 并重启。
  - 升级后入口恢复隐藏。
- 公开的 1.2.2 插件代码也从同一份 v1.1.1 副本升级成功：171 个素材文件和设置文件未变。
