## 验证

- 159 项 Python 测试，30 项 Node 测试通过，无窗口模式。
- 打包 EXE：8 个实机场景通过后提前结束（其余场景未在本构建上运行）：升级、伪造镜像被拒、经镜像升级、下载中断、安装中断和启动失败回滚。更新窗口场景未在本产品上单独运行；其更新代码与 DeepSeek 版相同，该版窗口已实测。GitHub 和镜像由本机代理模拟。
- 手动检查窗口的实测（打包 EXE）：按钮只有一键更新、打开更新页面、备份配置与素材、忽略此版本、稍后提醒；带格式的说明显示为纯文本；点击一键更新升级到 v1.2.3，素材哈希和个人设置不变。
- 更新校验、恢复和回滚的代码相比 v1.2.1 未改动，其完整验证见 [v1.2.1 记录](UPDATE-VALIDATION-v1.2.1.md)。
