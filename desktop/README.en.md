# Shorekeeper for DeepSeek Harness — full desktop runtime

This directory contains the Windows runtime for the independently published Harness marketplace edition.

See the [installation and feature guide](../README.md), [validation record](../docs/VALIDATION.md), and [data and runtime notes](../docs/SECURITY.md).

The marketplace edition retains the full desktop settings, media, paired voice captions, interactions, balance, lock and click-through, and portable configuration. Desktop shortcut creation is omitted. Install and enable `dsh-shorekeeper` in Harness; do not install the legacy standalone bridge for this edition.

The original standalone edition remains available at https://github.com/Doya16/shorekeeper-deepseek-pet.
