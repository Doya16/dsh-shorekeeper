# 守岸人桌宠 · Harness 市场完整版

Windows 10/11 x64。基于已发布的守岸人 DeepSeek 桌宠 v0.5.1，保留完整自定义和迁移功能，移除创建桌面快捷方式。

首次使用请在 Harness 安装并启用 `dsh-shorekeeper`，从插件入口安装并启动完整版。右键桌宠 → 设置，可调整字体与大小、交互工作室、桌面与声音、保存与迁移、连接和更新。

余额框可以隐藏：右键桌宠或余额框，在“刷新余额”下一项切换“隐藏余额框 / 显示余额框”；也可在设置的“余额框大小”旁勾选。隐藏后不留空白，选择自动保存并随配置迁移。

旧独立版的配置与素材 ZIP 可以直接导入。导出 Windows 便携完整包后，可在新电脑完整解压、启用 Harness 插件，再启动桌宠。账户登录与聊天记录不在导出包中。
