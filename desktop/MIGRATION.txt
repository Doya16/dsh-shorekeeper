守岸人 DeepSeek Harness 完整版插件 · 保存与迁移

设置自动保存。右键 → 设置 → 保存与迁移，可立即保存、导出配置素材包或 Windows 便携完整包。
完整包携带运行程序、GIF、音频、每条字幕、字体及全部桌宠设置。

换电脑：
1. 安装官方 DeepSeek Harness 并登录。
2. 安装并启用 dsh-shorekeeper 插件。
3. 点击 Harness 内的守岸人桌宠入口，下载并安装完整版、启动桌宠。
4. 设置 → 保存与迁移 → 导入自己的配置与素材 ZIP。
5. 新任务启动后自动跟随，可在连接设置中选择会话。

导出的完整包也可解压到可写目录，手动启动“守岸人DeepSeek桌宠启动.exe”。
